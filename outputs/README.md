# outputs/

Generated files land here (git-ignored). Running `notebooks/LandTrendr_AlphaEarth.ipynb`
produces:

- `lt_training_stats_all_assets.csv` — per-band mean/std/percentile stats for all 15 LandTrendr assets
- `lt_training_corr_all_assets.csv`  — inter-band correlation analysis
- `lt_training_asset_summary.csv`    — training pixel counts and area per asset
